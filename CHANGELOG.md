# Unpublished spike history

These versions identify private source candidates, not npm or consumer releases.
Pin exact reviewed commits when evaluating them; never use a floating version or
this history as permission to merge/deploy. Shared home and real site adapters
remain required before an installable release.

## 0.1.0-alpha.4

Register explicit site-owned extension kinds, assert absolute London winter/DST
values, and log source head/clock/input hashes in opt-in source probes. Document
platform clock ownership and the legacy wrapper's UTC-only meaning. Labelled spike
approval for alpha.3 does not extend to this successor or permit main merge.

## 0.1.0-alpha.3

Validate all routable content and collisions before publication selection, wire
behavior tests into verify, strengthen matched guard tests, use frozen callback
copies, narrow route/kind policy, and pin/move source probes out of test discovery.
Require finite now/evaluatedAt and source-derived UTC availableAt, enforce update
instant bounds and preserve London/DST display-date separation. The projection now
returns a receipt with entries; the explicit date-only wrapper retains its fixture
array output. This is a breaking private-spike API change, not a released upgrade.
Real schemas/adapters, typed installable release, private-body build scan and retired
URL disposition remain open adoption requirements.
